How it works: edit the shop, prices, product photos, impact numbers or phone below. Changes publish automatically after you stop typing. You can also press Save & publish in the bottom bar at any time. The changes are saved to Neon and appear on the website immediately. Download backup is optional and keeps an offline copy for your web person.

Shop products

These appear on the Shop page and the home page preview (first 4). Use the arrows to reorder; unticking "Show on site" hides a product without deleting it.

Impact numbers & descriptions

Edit all nine impact cards. The first three numbers also update the matching home-page animation values everywhere they appear.

Contact phone

Replaces the "+91 XXXXX XXXXX" placeholder in the footer, pick-up page and contact page. Leave empty to keep the placeholder.

Gallery & Events

Photos and events shown on the Gallery page. Paste an image link (or leave it empty for a "photo coming soon" tile). Use the arrows to reorder.

Admin password

Change the password you use to open this dashboard. It must be at least 8 characters and include an uppercase letter, a lowercase letter, a number and a special symbol.

  • 8+ characters
  • Uppercase letter
  • Lowercase letter
  • Number
  • Special symbol
